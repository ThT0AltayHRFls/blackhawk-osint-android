# Katkıda Bulunma Rehberi

## Nasıl Katkıda Bulunabilirisin?

1. **Fork** - Bu repository'yi fork et
2. **Branch** - Yeni bir branch oluştur (`git checkout -b feature/ozellik`)
3. **Commit** - Değişiklikleri commit et (`git commit -am 'Açıklama'`)
4. **Push** - Branch'i push et (`git push origin feature/ozellik`)
5. **Pull Request** - Pull request aç

## Kod Standartları

- MVVM pattern kullan
- Async/await ile asynchronous işlemler
- Tüm public metodlar exception handle etsin
- Clean Code prensiplerini izle
- Yorum ve documentation ekle

## Test Etme

Katkı yapmadan önce:
- [ ] Debug modunda çalıştır
- [ ] Tüm ekranları test et
- [ ] Release modunda derle
- [ ] Hata loglarını kontrol et

## Issue Raporu

Hata bulursan:
1. Issue açı
2. Detaylı açıklama yaz
3. Ekran görüntüsü veya log ekle

## Feature İstekleri

Yeni özellik istersen:
1. Önce discussion aç
2. Kullanım durumunu açıkla
3. Önerileri ve görüşleri dinle
