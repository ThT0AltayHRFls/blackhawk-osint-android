# BlackHawk OSINT Tool

**Türkiye'nin Yerli ve Milli Açık Kaynak İstihbarat Aracı**

## Özellikler

✅ Çoklu Kaynak Arama (NewsAPI, Reddit, Web)
✅ 3D Dünya Haritası
✅ Premium PDF Raporları
✅ Çoklu Dil Desteği (TR, EN, AR)
✅ Lokal Veritabanı (SQLite)
✅ İnternet Olmadan Çalışma
✅ Günlük Bildirimler
✅ Profesyonel HD Tasarım

## Sistem Gereksinimleri

- Android SDK 26+
- .NET 8.0
- Visual Studio 2022

## Kurulum

```bash
git clone https://github.com/yourusername/BlackHawk.git
cd BlackHawk
dotnet restore
dotnet publish -f net8.0-android -c Release
```
